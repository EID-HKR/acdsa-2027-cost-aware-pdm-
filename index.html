Dataset and provenance

Source: Predictive Medical Equipment Maintenance System (PMEMS), Swarnodip Nag. Only the ventilator subset (220 observations) was used. The dataset is synthetic and does not represent clinically validated device behavior.

Rights: Neither the original dataset nor the ventilator-only extract is redistributed here. Download the data from the original repository, respecting its terms, and select records where equipment_type is Ventilator. The exact upstream commit used for the supplied workbook has not been established; see README for reproducibility limitations.

Scientific scope: The code is an independent reconstruction of the revised experiment, not a copy of the unavailable original code or a clinical validation.
